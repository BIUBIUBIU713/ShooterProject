# ShooterSam 演示录制清单

目标：制作 60–90 秒的实机视频，让观看者快速看到战斗、区域推进与 Boss。视频完成后将真实链接加入根目录 README 与简历；本清单不代表已经录制完成。

## 镜头顺序

| 时长 | 内容 | 建议字幕 |
| --- | --- | --- |
| 0–10 秒 | 直接展示移动、射击、命中反馈 | ShooterSam / UE5.7 个人玩法项目 |
| 10–25 秒 | 击杀敌人、波次变化、武器充能 | 波次战斗与资源管理 |
| 25–45 秒 | 一次区域门或补给交互，再展示供电／升级 | 区域推进与交互玩法 |
| 45–75 秒 | Boss 入场、普通攻击和半血技能，剪掉等待 | Boss 遭遇与阶段变化 |
| 75–90 秒 | Boss 死亡或撤离结算，最后显示仓库地址 | 自主构思 / C++ 与蓝图 / AI 辅助开发 |

连续试玩不必在 90 秒内完成。可分段录制再剪辑；波次、金币等状态发生跳转时用字幕说明，不把剪辑伪装成无间断流程。

## 录制前

- 固定窗口与分辨率，确认画面、游戏音量、鼠标捕获正常。
- 先走一遍路线，确认交互位置、Boss 触发前置条件和结算方式。
- 准备一个短的镜头清单；先展示玩法，避免录大量编辑器设置过程。
- 整理桌面通知，避免把联系方式、聊天或其他窗口录进视频。
- 录制用普通运行模式；NullRHI 自动化不产生可用的游戏画面。

## 完成标准

- 开头 10 秒能看到实际玩法，每段字幕与画面相符。
- 射击、交互、Boss 三类内容都出现；没有长时间空跑或明显卡死。
- 手机或另一个浏览器能正常打开视频链接，声音不盖过必要讲解。
- 不标注未经实测的“稳定 60 FPS”等性能成绩。

有录像后，再选 2–3 张清晰截图用于 README；不要用生成图代替实机画面。
