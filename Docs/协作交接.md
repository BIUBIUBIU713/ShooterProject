### 历史误判：返岗分支需重挂（已撤回，不作为操作指引）

2026-09-24 由 `ShooterSam.RegionGuards.MeleeTree` 读出的实际结构：

```text
Selector（根）
  [服务] Update Attack Range
  [服务] Update Guard Target
  [装饰器] Blackboard Based Condition        ← 多余的装饰器，根节点上不该有
  [装饰器] TargetActor Is Set
├─ Sequence（空的）
├─ Move To
├─ Wait
└─ Sequence：Combat
   [服务] Focus Melee Target
   [装饰器] IsInAttackRange Is Set
   [装饰器] HasLineOfSight Is Set
   ├─ Sequence：Attack【装饰器】Blackboard Based Condition
   │  └─ Random Melee Attack
   └─ （原追击分支）
```

目标是：

```text
Selector（根）
  [服务] Update Attack Range
  [服务] Update Guard Target
  [装饰器] TargetActor Is Set
├─ Sequence（返岗，根 Selector 的第一个子节点）
│  [装饰器] Blackboard：GuardReturning / Is Set / Notify Observer=On Result Change / Observer Aborts=Both
│  ├─ Move To（Blackboard Key=GuardHomeLocation，Acceptable Radius=50，Observe Blackboard Value 勾选）
│  └─ Wait（Wait Time=0.2）
└─ Sequence：Combat（原有全部结构不变）
```

编辑器里的操作：把根 Selector 下的 `Move To` 和 `Wait` 拖到那个 `Sequence` 上，让它们成为它的子节点；
再在 `Sequence` 上 `Add Decorator → Blackboard`，选 `GuardReturning`、`Key Query=Is Set`。
根节点上那个 `Blackboard Based Condition` 装饰器建议删掉。

### 2026-09-24：第二个近战名额生成失败（已修复）

`RegionGuardSpawner` 第一轮 PIE 只生成 5/6，日志反复出现：

```text
LogSpawn: Warning: SpawnActor failed because of collision at the spawn location
          [X=2438.009 Y=6010.320 Z=100.000] for [BP_RegionMeleeGuard_C]
Error: Guard spawn failed: region=Barracks slot=1 after 20 attempts. Check spawn collision.
```

根因是出生点本身，不是蓝图或生成器配置：`TargetPoint2` 所在位置的竖直空间被几何体占用，
胶囊无法生成，`AdjustIfPossibleButDontSpawnIfColliding` 每 0.5 秒重试一次，20 次后放弃该槽位。

**已验证的排查结论**：第一次只把该点的 `Z` 从 100 抬到 134.259（`X/Y` 未动）仍然失败，
说明挡住它的是竖直障碍而不是地面——**只调高度没用，必须横向挪开**。
最终把 `TargetPoint2` 移到 `(2823.0, 6285.4, 121.8)` 后成功，改动前后的坐标已由检查脚本确认。

失败槽位被丢弃后会打上 `bHadSpawnFailure=true`，`CheckCleared` 要求
`SpawnedCount == GuardCount`，所以**只要有出生点失败，该区域的 `OnGuardsCleared` 永远不会广播**。
配新区域出生点时务必让每个点都有完整胶囊净空。
