# 僵尸模式地图设计详案（Lvl_Zombies）

> 配套文档：《ZombiesMode_设计文档.md》第 7 节（本详案为其细化版）
> 版本：v0.1（1 个月求职版范围：3 区域 + 可选屋顶）
> 坐标系：UE 标准（X 向东 / Y 向北 / Z 向上），单位 cm，网格吸附 100
> 说明：坐标为"建议摆位"，进编辑器后按网格微调即可

---

## 1. 设计目标与验收

**目标**：一张能完整支撑核心循环的线性地图——玩家从出生房一路推进到实验室，开 3 道门、买 3 把墙购武器，僵尸从窗外/裂缝/管道涌入。

**验收标准（第 1 周结束）**：
- [ ] 第一人称可在 3 个区域自由跑动、跳跃、无卡碰撞
- [ ] 3 道门洞、5+ 个窗户全部按点位清单就位
- [ ] NavMesh 烘焙通过，所有僵尸出生点能寻路到玩家
- [ ] 灯光氛围到位，无全黑死角

---

## 3. 区域详设

### 3.1 出生房（Spawn Room）— 1500×1200，中心 (0, 0)
- 墙体：高 400，厚 50；北墙 Y=+600，南墙 Y=-600，西墙 X=-750，东墙 X=+750
- **门1**：北墙正中，门洞宽 140 × 高 250
- **窗户 ×2**：北墙门两侧，窗洞宽 160 × 高 100，窗台高 200（窗外做 40cm 宽窗台沿）
- 内部：中央一张台子（掩体），无墙购（开局给手枪+刀）
- 灯光：2 盏暖白顶灯
- 玩家出生点：(0, -100, 0)，朝 +Y（面向门1）

### 3.2 庭院（Courtyard）— 3000×2000，中心 (0, 2200)
- 范围：Y 从 600 到 2600；南墙开**门1**洞，北墙开**门2**洞
- **窗户 ×4**：北墙门2两侧 X=±1000；东西墙中部 Y=1500
- **裂缝 ×2**（地板刷怪点）：(-700, 1000)、(700, 2000)
- **掩体 ×6**：立柱/半墙交错布置（见第 4 节掩体表），保证任何点位都有退路
- **墙购**：冲锋枪（西墙）、霰弹枪（东墙）
- 灯光：冷色月光天光 + 4 根柱灯，暗部多

### 3.3 实验室（Lab）— 2500×1500，中心 (0, 3350)
- 范围：Y 从 2600 到 4100；南墙开**门2**洞，北墙开**门3**洞
- **管道 ×2**（高位出生点）：(-900, 2800)、(900, 3800)，出生后跳落
- **门缝 ×2**：(-1000, 3400)、(1000, 3400)
- **墙购**：步枪（西墙）
- 设施（Phase 2 占位）：电源开关 (+900, 2900)、PaP 机 (-800, 3900)
- 掩体：3~4 个实验台
- 灯光：荧光灯蓝绿；通电前暗（0.6），通电后亮（2.0）

### 3.4 屋顶（Rooftop，可选）— 3000×2500，中心 (0, 5350)
- 南墙开**门3**洞；开阔决战区，少量掩体
- 楼梯口出生点 ×3
- 灯光：夜间天光

## 5. 流线设计

### 5.1 玩家流线
```
出生房(练枪) → 花500开门 → 庭院(买冲锋枪/霰弹枪, 中期主战场)
   → 花750开门 → 实验室(买步枪, 通电/PaP) → 花1000开门 → 屋顶(决战)
```
每开一道门 = 新的"风险+收益"台阶：更危险、但能买更好的武器。

### 5.2 僵尸流线
- 出生点在**玩家已解锁区域**内激活（门未开 → 该区域不刷怪，保证"门 = 安全线"）。
- 窗/裂缝/管道出生后：进入 NavMesh → 自动寻路到玩家 → 近战攻击。
- 每轮出生点轮换使用，避免玩家背板固定点位；第 3 轮起加入裂缝类（从脚下钻出，压迫感）。

### 5.3 轮次刷怪规则
| 规则 | 说明 |
|---|---|
| 激活范围 | 玩家当前所在区域 + 所有已开门区域 |
| 出生节奏 | 每秒 1~2 只，随轮次加快 |
| 同时存活上限 | 24 只 |
| 出生点轮换 | 每轮随机挑选 60% 的点位 |

## 6. Blockout 搭建步骤（编辑器操作清单）

> 用 `LevelPrototyping` 模块化方块，全部开网格吸附（100）。

1. **新建关卡**：`File > New Level > Empty`，保存为 `Content/Zombies/Maps/Lvl_Zombies`
2. **设置 GameMode**：World Settings → GameMode 选 `BP_ZombieGameMode`（未做前可先用 BP_ShooterSamGameMode 占位）
3. **铺地面**：每个区域一块地面方块（厚度 50，顶面 Z=0），区域间不留缝
4. **搭墙体**：高 400、厚 50，按 3.1~3.3 坐标围合；门洞留 140 宽
5. **开窗户**：墙洞 160 宽 × 100 高，窗台高 200；窗外加 40cm 宽窗台沿
6. **摆掩体**：立柱(200×200×300) / 半墙(200×100×150) / 实验台，按第 4 节表
7. **放 PlayerStart**：(0, -100) 朝 +Y
8. **放占位点**：门/墙购/僵尸出生点先放"Cube + ArrowComponent"占位，位置朝向按第 4 节表
9. **NavMesh**：拉 `NavMeshBoundsVolume` 覆盖 3 区域 → `Build Paths`（快捷键 P）
10. **灯光**：按第 7 节表摆放
11. **测试**：PIE 跑一圈——检查碰撞、寻路、出生点朝向、门洞通行

## 7. 灯光与氛围

| 区域 | 方案 | 亮度(建议) |
|---|---|---|
| 出生房 | 暖白顶灯 ×2（点光 3000 强度） | 2.0 |

## 8. NavMesh 注意事项

- Bounds Volume 覆盖**所有可走地面**（含窗台沿内侧 40cm）。
- 窗台沿高度 ≤ 40cm 或加小斜坡，确保僵尸能从出生点走到地面。
- 裂缝出生点：直接放在裂缝标记处（地面），出生后即寻路，无需挖洞。
- **每次改几何体后必须重新 Build Paths**，否则僵尸会原地发呆。
- 验证方法：PIE 里观察第 1 轮僵尸是否全部能走到玩家。
